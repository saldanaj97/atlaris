# Atlaris style guide

The canonical detailed specification is [Atlaris Design System](./design-system.md). Start with [DESIGN.md](../../DESIGN.md) before UI work. This compatibility page defines no separate colors, tokens, components or interaction rules.

The former [After Hours direction](./after-hours-direction.md) is historical and does not override the canonical specification.

JCS-86 adopts the shared runtime foundations; the full page and component redesign remains in progress. Current application code and tests govern shipped behavior; the canonical specification governs intended design, with its proposals and open decisions preserved.
